# Лабораторна робота №6. Замикання та декоратори як HOF

**Варіант 14 — планувальник повторів задач.** Політика затримки між спробами — це
замикання `attempt -> seconds` (`fixed_delay`, `exponential_delay` з верхньою межею),
яке передається у `@retries` як функція; `@timed` вимірює час усього плану повторів,
а `time.sleep` замінено на `fake_sleep`, що лише записує заплановані паузи.
Виконала: Поведа Анастасія, ФЕП-23.

## Цілі

- замикання, що утримують стан (`nonlocal`) і параметри політик;
- параметризовані декоратори як фабрики декораторів, `functools.wraps`;
- типізація обгорток через `ParamSpec`, `TypeVar`, `Protocol`;
- інжекція `clock` / `sleep` / `logger` / `time_fn` / `delay`, щоб тести були детермінованими.

## Порядок застосування декораторів

Декоратори застосовуються знизу вгору, тож у `app.py`:

```python
@timed("sync", ...)
@retries(attempts=4, delay=fixed_delay(0.5), sleep=fake_sleep)
def sync_task(): ...
```

виклик проходить `timed → retries → задача`: таймер вмикається один раз і охоплює всі
спроби разом із запланованими паузами, а `retries` бачить лише винятки самої задачі.
Якби `timed` стояв усередині, він вимірював би кожну спробу окремо і логував би
час навіть для невдалих. Кеш (`cached`) розміщено всередині `retries`: невдала спроба
не кешується, а після першого успіху повторні виклики не доходять до задачі.
